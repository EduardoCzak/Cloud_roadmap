## Comandos Linux praticados
- `pwd`: mostra o diretório atual.
- `ls`: lista arquivos e diretórios.
- `ls -l`: lista arquivos com detalhes.
- `mkdir`: cria diretórios.
- `touch`: cria arquivos.
- `cat`: exibe o conteúdo de arquivos.
- `cp`: copia arquivos.
- `mv`: move ou renomeia arquivos.
- `rm`: remove arquivos.
